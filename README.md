# Autism Spectrum Disorder (ASD)
Teach me autism. What is it? How to deal with it? Can it be fixed? How to live with it?

## Managing Sensory Overload
  - Use noise-canceling headphones in loud spaces.
  - Wear comfortable clothing with soft textures.
  - Create a quiet, low-stimulus recovery space at home.
  - Carry sensory tools like fidget items.

## Establishing Structure
  - Build predictable daily schedules for meals, work, and rest.
  - Use visual calendars, alarms, or apps to track tasks.
  - Plan ahead for changes in routine and transition times.

## Honoring Energy and Regulation
  - Allow safe self-regulation or stimming to release stress.
  - Reduce social and work demands when feeling burned out.
  - Rest and recharge instead of forcing constant social masking.

## Seeking Community and Support
  - Connect with peer-led autistic support groups online or locally.
  - Engage deeply with special interests and hobbies.
  - Seek neurodiversity-affirming psychotherapy if professional guidance is needed.
